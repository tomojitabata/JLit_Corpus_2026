# ⚠ numba を伴うので，numpy の版と噛み合わないと import 自体が落ちる。
# ⚠ **Intel Mac（x86_64）は版を固定すること。**
#    scripts/00_bootstrap_mac.sh は CPU を判定し，Intel なら下の固定を自動で行う
#    （-c で制約を掛けてからこのファイルを入れる）。手で入れるときだけ下を読む。
#    llvmlite の macOS x86_64 wheel は **0.45.1 が最後**で，0.46 以降は

#      numba 0.62.1 ＋ llvmlite 0.45.1（numpy<2.4）
#    で，入れ方は
#      uv pip install --python "<sys.executable の値>" \
#          --only-binary :all: \
#          "numba==0.62.1" "llvmlite==0.45.1" "numpy<2.4" umap-learn
#    numpy が 2.3 系に下がるが，pandas 3 / scipy 1.18 / scikit-learn 1.9 /
#    matplotlib 3.11 はいずれも numpy 2.3 で動く（2026-09-22 に確認）。
#    Apple Silicon では版の固定は要らない。
# ⚠ **uv add はプロジェクト（pyproject.toml のある場所）単位である。**
#    00_bootstrap_mac.sh は作業フォルダ ~/Documents/dh_project に
#    pyproject.toml と .venv を作り，リポジトリはその中に clone する。
#    したがってリポジトリの中で `uv add umap-learn` を走らせれば，uv は
#    親の dh_project を見つけ，**カーネルと同じ .venv** に入れる。
#    **uv sync は使わないこと**（このファイルで入れたものを消す）。
#    dh_project の外に clone した場合などは，インタプリタを名指しする:
#      uv pip install --python "<sys.executable の値>" umap-learn
#    sys.executable は  import sys; print(sys.executable)  で確かめる。
#    入れたら**カーネルを再起動**すること。
# ⚠ カーネル自体が別の Python（anaconda3 など）のときは，
#    Kernel → Change Kernel で「Python (JLit)」に切り替える。
