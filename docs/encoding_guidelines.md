# テクスト符号化方針（JLit v2）

本コーパスの XML 符号化と正規化の決定事項。**分析結果を左右する決定はすべてここに記す。**
実装は `scripts/03_aozora2xml.py` と `scripts/04_normalise.py`，
設定は `config/pipeline.yaml`。

---

## 0. 基本原則

> **削らない。分離する。何を数えるかは後段の設定で決める。**

v1 コーパスの欠陥（外字592箇所の喪失，奥付の混入，ルビの不可逆な消去）は
いずれも「本文から要らないものを正規表現で削る」方針の副作用である。
削除は不可逆であり，記録も残らない。

v2 では，青空文庫 XHTML のすべての構成要素を XML の要素・属性に写像し，
解析用テクストはそこから**決定的に生成**する。生成規則は設定ファイルに書く。

---

## 1. 取得元

| 項目 | 決定 | 理由 |
|---|---|---|
| 配布形式 | **XHTML 版**（`.html`） | ルビ・注記・外字・奥付が要素で区切られる |
| 書誌 | `list_person_all_extended_utf8.csv` | 初出・NDC・文字遣い・底本が一元的に得られる |
| 文字遣い | 既定 **新字新仮名** | 同一作品に複数版があるとき（例：啄木『鳥影』card46947 / card4695） |
| 分冊 | 個別に取得し，作品単位で結合 | 『夜明け前』4分冊，『家』上下 |

**旧字旧仮名版を採らない決定**は，正書法の変化そのものを研究対象にしないことを
意味する。この制約は成果物に明記すること。

## 2. XML の要素

```xml
<TEI>
  <teiHeader>
    <fileDesc>
      <titleStmt><title>渋江抽斎</title><author key="000129">森鴎外</author></titleStmt>
      <publicationStmt>
        <idno type="jlit">JLIT063</idno>
        <idno type="aozora_work">2058</idno>
        <ref target="https://www.aozora.gr.jp/cards/000129/card2058.html"/>
      </publicationStmt>
      <sourceDesc>
        <bibl type="first_publication" n="「大阪毎日新聞」…1916年1月13日～5月17日">
          <date from="1916" to="1916"/></bibl>
        <bibl type="base_text">底本：「渋江抽斎」岩波文庫 / …</bibl>
      </sourceDesc>
    </fileDesc>
    <profileDesc><textClass>
      <classCode scheme="NDC">913</classCode>
      <catRef scheme="orthography" target="新字新仮名"/>
    </textClass></profileDesc>
  </teiHeader>
  <text><body>
    <head n="2" rend="o-midashi">その一</head>
    <p>池田氏、名は<g ref="1-14-22">侔</g>、字は河澄。</p>
    <p><said>「わたくしは<ruby rt="こ">此</ruby>に記述したい。」</said>と云つた。</p>
    <p><quote>『武鑑』</quote>に接続する<note type="textual">「○」は底本では「●」</note>。</p>
    <ab rend="indent-3"><p>三十七年如一瞬。</p></ab>
  </body></text>
</TEI>
```

| 要素 | 意味 | 解析ストリームでの扱い |
|---|---|---|
| `<head n="1|2|3">` | 見出し | 独立行として残す（`speech` では除外） |
| `<p>` | 段落 | — |
| `<said>` | 会話（第一階層の会話符） | `narration` では除外／`speech` ではこれのみ |
| `<said part="I\|M\|F">` | 段落をまたぐ会話の断片 | 同上（断片は連結して1つの会話と見る） |
| `<quote type="embedded">` | 書簡・演説など埋め込みテクスト | 含める。内側の `<said>` は会話として数える |
| `<quote>` | 第二階層の会話符による引用・書名 | 含める |

| `<ruby rt="よみ">` | ルビ付き語 | **基底文字のみ**を採り，`@rt` は除外 |
| `<g ref="面-区-点">` | 外字 | 復元した文字に置換 |
| `<g ref="unresolved" n="注記">` | 復元不能な外字 | `〓` に置換して計数 |
| `<note type="...">` | 入力者注・校訂注・組版指示 | **常に除外** |
| `<ab rend="indent-N">` | 字下げブロック | 含める |
| `<lb/>` | 底本の改行 | 段落化に使い，出力には残さない |

### 会話標示（`<said>`）の5つの規則

会話の標示は素朴に実装すると必ず壊れる。括弧の対応は正規言語ではないので
走査で決めるほかなく，しかも底本の組版慣習が作品ごとに違う。次の5点を守る。

**1. 段落の内側で開閉を完結させる。**
長い会話は底本の改行で段落が切れ，複数段落にまたがる。`<said>` を
段落をまたいで開いたままにすると XML が非整形式になる
（`<p><said>…</p><p>…</said></p>`）。段落末でいったん閉じ，
続きの段落の冒頭で開き直す。断片には TEI の `@part` を付け，
`I` 最初・`M` 中間・`F` 最後とする。会話の数え上げでは `@part` の
連なりを1つの会話と見る（変換レポートの `said` が会話数，
`said_parts` が要素数）。

**2. 第一階層の会話符は作品ごとに判定する。**
明治〜大正の底本では `『』` を第一階層に使い，`「」` を書名や引用語句に
充てるものが珍しくない（島崎藤村『破戒』は `「」` 47 に対し `『』` 1,574）。
一律に `「」` を会話と見ると，そうした作品の会話が丸ごと落ちる。
閉じた対の数を数えて多いほうを第一階層とし，`teiHeader` の
`<catRef scheme="speech_mark">` に記録する。第二階層は `<quote>` にする。
入れ子は作らない。

**3. 継続引用符を継続として読む。**
長い引用が段落や章をまたぐとき，底本は**各段落（各章）の頭に開き括弧を
繰り返し，閉じ括弧は引用全体の末尾に一度だけ置く**。夏目漱石『こころ』下
「先生と遺書」はこの型で，56 章それぞれの冒頭に `「` があり閉じるのは
最終章だけである。**段落頭の開き括弧が入れ子を表すことは日本語の組版では
まずない**ので，会話が開いたまま段落が開き括弧で始まったら同一の引用の
継続として扱う。接続回数は `said_cont` 列に出る。

**4. 長大な引用は会話ではなく埋め込みテクストとする。**
`--embed-min`（既定 8）段落以上にわたる引用は，対話ではなく書簡・演説・
手記といった埋め込まれたテクストである。これを `<said>` にすると
『こころ』下の全体が「会話」になってしまうので `<quote type="embedded">`
とし，**その内側の対話を `<said>` として別に標示する**。件数は
`quote_embedded` 列に出る。

**5. 閉じ括弧のない `「` は，それだけを降格する。**
底本には閉じ括弧を欠く `「` が実際に現れる（強調の用法，組版の都合，
入力の誤り，そして福沢諭吉『福翁自伝』のように `「` で起こして
「と云う」で閉じる口述筆記の方式）。`--max-par`（既定 150）段落以内に
閉じず，見出しの境界にも達したものは**その開き括弧だけをただの文字に戻し**，
同じ範囲にある**正しく閉じている対の標示は残す**。降格した括弧の数は
`said_unclosed` 列に出る。
**この値が大きい作品は底本の組版を確認すること**（`scripts/find_unclosed_quotes.py`
で位置を特定できる）。

### 会話文比率の 0 と欠測

**比率が 0 であることと，比率が測れないことは違う。** 変換器は作品ごとに
会話標示の信頼度を判定し，`teiHeader` の `<catRef scheme="speech_markup">` と
変換レポートの `speech_markup` 列に記録する。

| 値 | 条件 | 該当作品（108点中13点） |
|---|---|---|
| `none` | 会話符による標示が皆無 | 五重塔，たけくらべ，にごりえ，修禅寺物語，良夜，花月の夜，旧藩情，学者安心論，新らしき女の道 |
| `partial` | 未閉の割合 ≥ 0.20，または1万字あたりの会話数 < `--min-said-density`（既定 1.5） | 福翁自伝，遠野物語，十三夜，父帰る |
| `full` | 上記以外 | 95点 |

`none` の内訳は，雅俗折衷体で会話を地の文に溶かす作品（露伴・一葉），
戯曲（話者名と字下げで会話を示す），および会話をほとんど含まない短い論説である。
`partial` は口述筆記（福翁自伝は `「` 330 に対し `」` 38）と，
会話符を使わない文語の記述（遠野物語）である。

`04_normalise.py` は `full` 以外の作品の `speech_ratio` を**空欄（NA）**にする。
分析で `fillna(0)` をしてはならない。0 で埋めると，会話文比率を説明変数に
使うモデル（doc2vec の `category_effects`，話法の通時変化）が
「明治期は会話が少ない」という**存在しない傾向**を検出する。

なお，生成した XML は書き出す前に `ElementTree` で整形式かどうかを検査し，
壊れていればファイルを書かずにエラーとして報告する。

### `<note>` の下位分類

`type` は注記本文から自動判定する。

| type | 判定語 | 例 |
|---|---|---|
| `textual` | 底本では／ママ／誤植 | `［＃「裏」はママ］` |
| `layout` | 字下げ／傍点／太字／横組／罫囲み | `［＃ここから2字下げ］` |
| `figure` | 図／挿絵／写真 | `［＃図版］` |
| `gaiji` | 水準／U+ | `※［＃「广＋(炎/鳥)」、第4水準2-81-40］` |
| `editorial` | それ以外 | — |

`gaiji` と判定され，直前が `※` の場合は `<note>` にせず `<g>` に変換する。

## 3. 外字の復元

青空文庫の外字注記は JIS X 0213 の **面-区-点**（または Unicode）を与える。

```
※［＃「广＋(炎/鳥)」、第4水準2-81-40］
                      面 区  点
```

EUC-JIS-2004 の符号化規則で Unicode に確定的に変換できる。

| 面 | バイト列 |
|---|---|
| 面1 | `0xA0+区, 0xA0+点` |
| 面2 | `0x8F, 0xA0+区, 0xA0+点` |

実装は `lib/aozora.menkuten_to_char()`。検証済みの対応例：

| 注記 | 復元 |
|---|---|
| 第3水準1-14-22 | 侔 |
| 第3水準1-15-25 | 噲 |
| 第3水準1-84-7 | 噓 |
| 第4水準2-78-35 | 泖 |
| 第4水準2-81-40 | 㽷 |

復元できない場合は `<g ref="unresolved" n="注記本文"/>` として保存し，
解析ストリームでは `〓` に置換して**数えられる状態**にする。
（v1 では `※` が残るだけで，何が失われたか分からなかった）

**v1 で失われていた例**

| 作品 | v1 の状態 | 原文 |
|---|---|---|
| 徳冨蘆花『不如帰』 | `合 ※ の 式` | 合巹（ごうきん）の式 |
| 藤村『夜明け前』 | `檜木、椹、明檜、高野槇、※` | 鼠子（ねずこ）＝木曾五木 |
| 岡本かの子『生々流転』 | `掻き ※ り ながら` | 毟（むし）り |

## 4. 踊り字（iteration marks）

| 記号 | 処理 | 理由 |
|---|---|---|
| `々` | **展開しない** | UniDic に語彙素として登録済み（人々・時々・我々） |
| `ゝ` | 直前の平仮名を反復（直前が濁音なら清音化） | UniDic 未登録 |
| `ゞ` | 直前の平仮名を濁音化して反復 | 同上 |
| `ヽ` `ヾ` | 片仮名版 | 同上 |
| `／＼` `〳〵` | 直前の仮名連続（2–4字）を反復 | 同上 |
| `／″＼` `〴〵` | 同上・濁音化 | 同上 |
| `〃` | `<seg type="ditto"/>` として除外 | 表・リスト内の同上記号 |

### くの字点の曖昧性

くの字点は「直前の何字を繰り返すか」が原理的に決まらない。
本パイプラインは**直前の仮名連続（最大4字）**を単位とするヒューリスティクスを
用い，機械推定であることを記録に残す。誤展開が疑われる箇所は
`normalise_report.csv` の `kunoji_expanded` を手がかりに点検する。

### なぜ正規化が必要か

v1 における仮名踊り字の偏在（546箇所が6ファイルに集中）は，
**文体差ではなく底本の正書法差**である。

| ファイル | ゝ | ゞ | ヽ | ヾ | 文字遣い |
|---|---:|---:|---:|---:|---|
| 藤村『破戒』 | 218 | 0 | 0 | 0 | 新字旧仮名 |
| 藤村『夜明け前』『家』『新生』『千曲川』 | 0 | 0 | 0 | 0 | 新字新仮名 |
| 岡本かの子『生々流転』 | 8 | 183 | 0 | 0 | 新字新仮名 |
| 石川啄木『鳥影』 | 2 | 5 | 66 | 2 | 新字旧仮名 |

正規化しないと，同一著者内でも底本差が文体差として検出される。

## 5. 文字の正規化

| 対象 | 処理 | 備考 |
|---|---|---|
| 全角ラテン文字・全角数字 | NFKC で半角化 | `Ｂ・Ｄ` → `B・D` |
| 仮名・約物 | **NFKC をかけない** | `「」` が変形するため |
| 波ダッシュ `〜` U+301C | 全角チルダ U+FF5E に統一 | 環境依存の異体 |
| 全角マイナス U+2212 | ASCII ハイフンに統一 | — |
| 連続空白・改行 | 整理 | — |

**漢数字と算用数字は統一しない。** 「十九年」と「19年」は書記上の選択であり，
文体の指標になりうる。統一すると情報が失われる。
（`海野十三『敗戦日記』`366箇所，`火星兵団` 126箇所の算用数字は，
 それ自体が日記／少年向け新聞小説という媒体の特徴である）

## 6. 形態素解析

| 項目 | 決定 |
|---|---|
| 辞書 | **近現代口語小説UniDic（`unidic-novel` v202512）**。2026-09-22 決定（`docs/dictionary_comparison.md` §10） |
| 検算用の辞書 | 近代文語UniDic（`unidic-kindai-bungo` v202512）。A_文語体の助動詞率の確認にのみ使う |
| 使わない辞書 | 現代書き言葉（cwj）。同じ 111 点で未知語率が novel の 3.9 倍（0.66% 対 0.17%） |
| 単位 | 短単位（SUW） |
| 分析語形 | `lemma_key`（下記の規則） |
| 同形異義接尾辞 | 既定で除去（`私-代名詞` → `私`） |
| 補助記号・空白 | 既定で除外（`--keep-punct` で保持可） |

### `lemma_key` の規則

```
固有名詞（pos1=名詞, pos2=固有名詞） → orthBase（なければ表層形）
それ以外                            → lemma（なければ orthBase → 表層形）
```

UniDic の `lemma` は異表記（噓／嘘，云う／言う）を統合するので通時比較に向くが，
**固有名詞では片仮名の読みになる**（渋江 → シブエ）。上の規則で回避する。

### 出力する3系統

| ファイル | 内容 | 用途 |
|---|---|---|
| `tokens_lemma/` | 全品詞の語彙素 | 文体計量・word embedding |
| `tokens_surface/` | 表層形 | 表記の変化を扱うとき |
| `tokens_content/` | 名詞・動詞・形容詞・副詞の語彙素 | トピックモデル |

`tsv/` には1行1形態素で全素性を残す。**後から別の方針で作り直せる**ようにする。

### 未知語率は表記別に見る

未知語率は**仮名遣い・字体と強く相関する**。下は **cwj（現代語辞書）で
測った旧い実測値**（108点）である。辞書を `unidic-novel` に替えたので
**この表の水準はもう当てはまらない**（全体で 0.66% → 0.17%）が，
「表記の群ごとに見る」という読み方は変わらない。

| 表記 | 件数 | 中央値 | 最大 |
|---|---:|---:|---:|
| 新字新仮名 | 85 | 0.22% | 1.44% |
| 新字旧仮名 | 19 | 0.61% | 1.81% |
| 旧字旧仮名 | 4 | 1.81% | 2.95% |

> **⚠ 測り直したら，この表を差し替えること**（`data/tokens/tokenise_report.csv`
> を `kana_orthography` で群分けする）。`unidic-novel` では残る未知語の
> 大半がカタカナ外来語になるため，**未知語率は「正書法の乱れ」ではなく
> 「外来語の密度」を測る指標に変わっている**
> （`docs/dictionary_comparison.md` §11）。

**全体の中央値と比べてはいけない。** 旧字旧仮名の作品が軒並み警告になり，
本当の異常が埋もれる。`99_validate.py` は `kana_orthography` で群に分け，
**同じ表記の仲間の中で外れているか**を見る。

### 表記は時代と交絡している

旧字旧仮名4点の初出年は 1892・1895・1910・1913 で，すべて大正以前である。
つまり「時代が下ると未知語率が下がる」という観察は，**言語の変化ではなく
底本の表記方針を測っている**おそれがある。通時比較では

1. `kana_orthography` を共変量として持つ（メタデータの列にある）
2. 旧字旧仮名を除いた場合と含めた場合で結果を比べる

の2つを必ず行うこと。表記を理由に個別の作品を落とすのは，**同じ基準を
既存作品にも当てられるときに限る**（『即興詩人』161,630語も旧字旧仮名である）。

### 採否を数値で決めるとき

新規候補が旧字旧仮名しか無い場合（長塚節『土』など）は，取得して
未知語率を測ってから決める。目安:

| 未知語率 | 判断 |
|---|---|
| 〜2.95%（既存の旧字旧仮名の最大値まで） | 採用。既存作品と同じ扱い |
| 2.95〜4% | `unknown_words.csv` を見る。方言語彙・固有名詞なら**内容**であって雑音ではない。採用してよい |
| 4% 超 | 見送る。解析が信用できない |

## 7. 記録すべきこと

再構築のたびに次を `logs/` に日付つきで残す。

1. `config/pipeline.yaml` のコピー
2. `data/aozora/fetch_log.csv`（取得日・作品ID・底本）
3. `data/xml/conversion_report.csv`（外字の復元数／未解決数）
4. `data/plain/normalise_report.csv`（踊り字の展開数）
5. `data/tokens/tokenise_report.csv`（未知語率）＋ `unknown_words.csv`
6. `99_validate.py` の出力

**「どの辞書のどの語形で，何を除いて数えたか」が再現できない数値は，
論文に載せてはいけない。** v1 では同一作品の2ファイルで分かち書きが
食い違っていた（`Ｂ ・ Ｄ` と `Ｂ・Ｄ`）が，記録がないため原因を特定できない。
