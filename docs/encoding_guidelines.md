# テクスト符号化方針（JLit v2）

本コーパスの XML 符号化と正規化の決定事項。**分析結果を左右する決定はすべてここに記す。**
実装は `scripts/03_aozora2xml.py` と `scripts/04_normalise.py`，
設定は `config/pipeline.yaml`。

---

## 0. 基本原則

> **削らない。分離する。何を数えるかは後段の設定で決める。**

v1 コーパスの欠陥（外字592箇所の喪失，奥付の混入，ルビの不可逆な消去）は
いずれも「本文から要らないものを正規表現で削る」方針の副作用である。
削除は不可逆であり，記録も残らない。

v2 では，青空文庫 XHTML のすべての構成要素を XML の要素・属性に写像し，
解析用テクストはそこから**決定的に生成**する。生成規則は設定ファイルに書く。

---

## 1. 取得元

| 項目 | 決定 | 理由 |
|---|---|---|
| 配布形式 | **XHTML 版**（`.html`） | ルビ・注記・外字・奥付が要素で区切られる |
| 書誌 | `list_person_all_extended_utf8.csv` | 初出・NDC・文字遣い・底本が一元的に得られる |
| 文字遣い | 既定 **新字新仮名** | 同一作品に複数版があるとき（例：啄木『鳥影』card46947 / card4695） |
| 分冊 | 個別に取得し，作品単位で結合 | 『夜明け前』4分冊，『家』上下 |

**旧字旧仮名版を採らない決定**は，正書法の変化そのものを研究対象にしないことを
意味する。この制約は成果物に明記すること。

## 2. XML の要素

```xml
<TEI>
  <teiHeader>
    <fileDesc>
      <titleStmt><title>渋江抽斎</title><author key="000129">森鴎外</author></titleStmt>
      <publicationStmt>
        <idno type="jlit">JLIT063</idno>
        <idno type="aozora_work">2058</idno>
        <ref target="https://www.aozora.gr.jp/cards/000129/card2058.html"/>
      </publicationStmt>
      <sourceDesc>
        <bibl type="first_publication" n="「大阪毎日新聞」…1916年1月13日～5月17日">
          <date from="1916" to="1916"/></bibl>
        <bibl type="base_text">底本：「渋江抽斎」岩波文庫 / …</bibl>
      </sourceDesc>
    </fileDesc>
    <profileDesc><textClass>
      <classCode scheme="NDC">913</classCode>
      <catRef scheme="orthography" target="新字新仮名"/>
    </textClass></profileDesc>
  </teiHeader>
  <text><body>
    <head n="2" rend="o-midashi">その一</head>
    <p>池田氏、名は<g ref="1-14-22">侔</g>、字は河澄。</p>
    <p><said>「わたくしは<ruby rt="こ">此</ruby>に記述したい。」</said>と云つた。</p>
    <p><quote>『武鑑』</quote>に接続する<note type="textual">「○」は底本では「●」</note>。</p>
    <ab rend="indent-3"><p>三十七年如一瞬。</p></ab>
  </body></text>
</TEI>
```

| 要素 | 意味 | 解析ストリームでの扱い |
|---|---|---|
| `<head n="1|2|3">` | 見出し | 独立行として残す（`speech` では除外） |
| `<p>` | 段落 | — |
| `<said>` | 会話（第一階層の会話符） | `narration` では除外／`speech` ではこれのみ |
| `<said part="I\|M\|F">` | 段落をまたぐ会話の断片 | 同上（断片は連結して1つの会話と見る） |
| `<quote type="embedded">` | 書簡・演説など挿入テクスト | 含める。内側の `<said>` は会話として数える |
| `<quote>` | 第二階層の会話符による引用・書名 | 含める |

| `<ruby rt="よみ">` | ルビ付き語 | **基底文字のみ**を採り，`@rt` は除外 |
| `<g ref="面-区-点">` | 外字 | 復元した文字に置換 |
| `<g ref="unresolved" n="注記">` | 復元不能な外字 | `〓` に置換して計数 |
| `<note type="...">` | 入力者注・校訂注・組版指示 | **常に除外** |
| `<ab rend="indent-N">` | 字下げブロック | 含める |
| `<lb/>` | 底本の改行 | 段落化に使い，出力には残さない |

### 会話標示（`<said>`）の5つの規則

会話の標示は素朴に実装すると必ず壊れる。括弧の対応は正規言語ではないので
走査で決めるほかなく，しかも底本の組版慣習が作品ごとに違う。次の5点を守る。

**1. 段落の内側で開閉を完結させる。**
長い会話は底本の改行で段落が切れ，複数段落にまたがる。`<said>` を
段落をまたいで開いたままにすると XML が非整形式になる
（`<p><said>…</p><p>…</said></p>`）。段落末でいったん閉じ，
続きの段落の冒頭で開き直す。断片には TEI の `@part` を付け，
`I` 最初・`M` 中間・`F` 最後とする。会話の数え上げでは `@part` の
連なりを1つの会話と見る（変換リポートの `said` が会話数，
`said_parts` が要素数）。

**2. 第一階層の会話符は作品ごとに判定する。**
明治〜大正の底本では `『』` を第一階層に使い，`「」` を書名や引用語句に
充てるものが珍しくない（島崎藤村『破戒』は `「」` 47 に対し `『』` 1,574）。
一律に `「」` を会話と見ると，そうした作品の会話が丸ごと失われる。
閉じた対の数を数えて多いほうを第一階層とし，`teiHeader` の
`<catRef scheme="speech_mark">` に記録する。第二階層は `<quote>` にする。
入れ子は作らない。

**3. 継続引用符を継続として読む。**
長い引用が段落や章をまたぐとき，底本は**各段落（各章）の頭に開き括弧を
繰り返し，閉じ括弧は引用全体の末尾に一度だけ置く**。夏目漱石『こころ』下
「先生と遺書」はこの型で，56 章それぞれの冒頭に `「` があり，閉じるのは
最終章だけである。**段落頭の開き括弧が入れ子を表すことは日本語の組版では
まずない**ので，会話が開いたまま段落が開き括弧で始まったら同一の引用の
継続として扱う。接続回数は `said_cont` 列に出る。

**4. 長大な引用は会話ではなく挿入テクストとする。**
`--embed-min`（既定 8）段落以上にわたる引用は，対話ではなく書簡・演説・
手記といった埋め込まれたテクストである。これを `<said>` にすると
『こころ』下の全体が「会話」になってしまうので `<quote type="embedded">`
とし，**その内側の対話を `<said>` として別に標示する**。件数は
`quote_embedded` 列に出る。

**5. 閉じ括弧のない `「` は，それだけを降格する。**
底本には閉じ括弧を欠く `「` が実際に現れる（強調の用法，組版の都合，
入力の誤り，そして福沢諭吉『福翁自伝』のように `「` で起こして
「と云う」で閉じる口述筆記の方式）。`--max-par`（既定 150）段落以内に
閉じず，見出しの境界にも達したものは**その開き括弧だけをただの文字に戻し**，
同じ範囲にある**正しく閉じている対の標示は残す**。降格した括弧の数は
`said_unclosed` 列に出る。
**この値が大きい作品は底本の組版を確認すること**（`scripts/find_unclosed_quotes.py`
で位置を特定できる）。

### 会話文比率の 0 と欠測

**比率が 0 であることと，比率が測れないことは違う。** 変換器は作品ごとに
会話標示の信頼度を判定し，`teiHeader` の `<catRef scheme="speech_markup">` と
変換リポートの `speech_markup` 列に記録する。

| 値 | 条件 | 該当作品（122点中14点） |
|---|---|---|
| `none` | 会話符による標示が皆無 | 五重塔，たけくらべ，にごりえ，修禅寺物語，良夜，花月の夜，旧藩情，学者安心論，新らしき女の道，藪の鶯 |
| `partial` | 未閉の割合 ≥ 0.20，または1万字あたりの会話数 < `--min-said-density`（既定 1.5） | 福翁自伝，遠野物語，十三夜，父帰る |
| `full` | 上記以外 | 108点 |

`none` の内訳は，雅俗折衷体で会話を地の文に溶け込ませる作品（露伴・一葉），
戯曲（話者名と字下げで会話を示す），および会話をほとんど含まない短い論説である。
`partial` は口述筆記（福翁自伝は `「` 330 に対し `」` 38）と，
会話符を使わない文語の記述（遠野物語）である。

`04_normalise.py` は `full` 以外の作品の `speech_ratio` を**空欄（NA）**にする。
分析で `fillna(0)` をしてはならない。0 で埋めると，会話文比率を説明変数に
使うモデル（doc2vec の `category_effects`，話法の通時変化）が
「明治期は会話が少ない」という**存在しない傾向**を検出する。

なお，生成した XML は書き出す前に `ElementTree` で整形式かどうかを検査し，
壊れていればファイルを書かずにエラーとして報告する。

### `<note>` の下位分類

`type` は注記本文から自動判定する。

| type | 判定語 | 例 |
|---|---|---|
| `textual` | 底本では／ママ／誤植 | `［＃「裏」はママ］` |
| `layout` | 字下げ／傍点／太字／横組／罫囲み | `［＃ここから2字下げ］` |
| `figure` | 図／挿絵／写真 | `［＃図版］` |
| `gaiji` | 水準／U+ | `※［＃「广＋(炎/鳥)」、第4水準2-81-40］` |
| `editorial` | それ以外 | — |

`gaiji` と判定され，直前が `※` の場合は `<note>` にせず `<g>` に変換する。

## 3. 外字の復元

外字（底本にあるが，使っている文字コードで直接は表せない文字）の復元は，
再構築でいちばん手間のかかった工程である。**なぜそこまでするのか，なぜ難しいのか，
どこまでが理想でどこからが現実か**を，先に書いておく。仕組みの説明は §3.6 にある。
用語は `docs/glossary.md` の Step 2，決定の経緯は `docs/corpus_design.md` §3.7。

### 3.1 なぜ重要か

1. **失われたことが，見えない。** v1 では外字注記 `※［＃…］` から括弧の部分だけが
   削られ，`※` が本文に残っていた（592 箇所・21 ファイル）。`※` は形態素解析では
   記号 1 字として数えられるので，例外も警告も出ない。**欠けていることに，
   数えてみるまで誰も気づかなかった。**
2. **語が壊れる。** 「合巹の式」は `合／※／の／式` になる。「合巹」という語は
   頻度表から消え，「合」という別の語が 1 つ増える。語数・異なり語数・未知語率・
   共起のすべてが，その 1 字のために狂う。
3. **その作品の鍵になる語に集中する。** 外字になるのは，人名・地名・屋号・
   動植物名・漢語の術語など，**その作品にしか出ない語**であることが多い。

   | 作品 | 外字 | うち最も多い字 | その字は何か |
   |---|---:|---|---|
   | 宮本百合子『道標』 | 999 | ヷ 990 | ロシアの人名・地名の表記（ヴァ） |
   | 森鴎外『伊沢蘭軒』 | 805（285 種） | 棭 230 | 人名「狩谷棭斎」 |
   | 岡本綺堂『飛騨の怪談』 | 194 | 𤢖 193 | 作品の中心になる怪異「山𤢖」 |
   | 森鴎外『即興詩人』 | 162 | 〻 67 | 二の字点（踊り字） |

   『飛騨の怪談』から 𤢖 が失われれば，**主題そのものが本文から消える**。
   作品の内容をいちばんよく表す語から先に失われる，というのはこういうことである。
4. **偏って起きる。** 再構築した 122 作品のうち外字を含むのは 66 作品で，
   その中央値は 5 箇所にすぎない。ところが『道標』と『伊沢蘭軒』の **2 作品
   だけで全体の 6 割**を占める。欠落の量は作品によって桁が違い，史伝や
   漢文脈の強い文章では字の種類も多い（『伊沢蘭軒』は 285 種）。**欠落の量が
   作家・ジャンル・文体と結びついている**ので，復元しないまま作品や時代を
   比べれば，言語の差ではなく欠落の量を測ることになる。
5. **元に戻せない。** 削ってしまった本文からは，何の字であったかを復元できない。
   v1 を直すのではなく，XHTML から作り直すほかなかったのはこのためである。

### 3.2 なぜ難しいか

機械的に済むのは一部で，残りは**一つずつ読んで判断する**作業になる。

| 困難 | 中身 | 起きること |
|---|---|---|
| 注記の形式が 3 つある | 面区点つき／Unicode つき／**字の説明だけ** | 3 つめは機械では復元できない |
| 番号の読み違い | 説明だけの注記の末尾 `160-9` は底本のページと行で，面区点ではない | 面区点と読むと，別の字か `※` が黙って本文に入る |
| 古いファイルは面区点を書いていない | 面区点の注記が導入される前の登録（『浮雲』『金色夜叉』『福翁自伝』『怪談牡丹灯籠』） | JIS X 0213 に在る字でも，説明から同定しなければならない |
| JIS に無いが Unicode に在る字 | 「巾＋兌」のような構成の説明だけがある | 構成から候補を挙げ，**文脈に合うか**を読んで確かめる（帨＝手巾） |
| Unicode に無い字 | 合略仮名「まいらせ候」，屋号記号，字母の分からない変体仮名 | 当てる字が存在しない。似た字で置き換えれば本文の改変になる |
| 入れ子の注記 | 「2-13-74 の斤を立刀に替えた字」のように，面区点が**別の字の説明の中**にある | 面区点を先に引くと，基の字（違う字）が入る |
| `※` がルビの中にある | 注記の直前が `</ruby>` になる | 「直前が `※` か」だけを見ていると取り逃がす（『伊沢蘭軒』に 74 箇所） |
| 注記が `※` を引用している | 底本についての編者注の中に `※` が出る | 外字ではないものが外字に化ける |
| 本文の `※` | 底本の編者が付けた注の印や伏字 | 欠陥ではない。機械的に「消し残し」と数えると誤る |
| 工程の途中で定義が落ちる | 分冊を結合するとき，字形の定義（`charDecl`）を結合し忘れた | 『家』下巻の 8 箇所が `〓` に戻った。**合計は「未解決 0」のままだった** |
| 解析器と書体 | 私用領域の文字は解析器には未知の記号で，書体が無ければ表示もできない | 復元しても，分析と表示で別の手当てが要る |

最後から 2 つめが教訓である。**合計だけを見ていると，1 作品の中で起きた
逆戻りに気づかない。** 件数は作品ごとに出して見る。

### 3.3 理想的な解決

1. **底本の画像と照合する。** 字形の説明からの同定は推定である。確定するには，
   底本（または影印）のその箇所を見るほかない。
2. **すべての字に，安定した識別子を持たせる。** Unicode に在る字は符号位置で，
   異体字は異体字セレクタ（IVS）で，Unicode に無い字は公開された字形の登録
   （文字情報基盤や GlyphWiki のようなもの）の識別子で指す。
3. **上流を直す。** 同定した結果を青空文庫に報告し，注記そのものに面区点や
   符号位置が入れば，以後の利用者は同じ作業をしなくて済む。
4. **字形を表示できる書体と，その字を含む辞書を用意する。** 復元した字が
   未知語にならず，画面でも読めるようにする。
5. **復元の由来を，1 字ごとに機械可読な形で残す。** TEI の外字モジュール
   （`<g>` と `charDecl`）がそのための仕組みである。

### 3.4 現実的な解決 — 本コーパスが採ったもの

理想の 1〜4 は，授業の準備の範囲では実行できなかった。採ったのは 5 を軸にした
次の方針である。

| 由来 | 何をしたか | XML | 箇所 |
|---|---|---|---:|
| 面区点・Unicode つき | 機械的に復元する（確定的） | `<g ref="1-84-7">噓</g>` | 2,733 |
| 説明だけ・Unicode に在る | **編者が同定して当てる**。根拠を対照表に書く | `<g ref="supplement" resp="editor">帨</g>` | 94 |
| Unicode に無い | 字を当てず，**字形を指し示す** | `<g ref="#id"/>` ＋ `charDecl` | 94 |
| 外字ではない注記 | 外字として数えない | — | 3 |
| 実体が分からない | `〓` にして**数えられる状態で残す** | `<g ref="unresolved" n="注記"/>` | 0 |

合わせて 2,921 箇所・451 種の字を復元した。方針は次の 5 つである。

1. **由来の違うものを，同じ顔で書かない。** 機械的な復元と編者の判断を，XML の
   上で区別する（`resp="editor"`）。あとで同定の誤りが見つかったとき，
   疑うべき範囲が分かる。
2. **編者の判断は，設定ファイルに根拠とともに置く。** `config/gaiji_supplement.tsv`
   に 64 件（Unicode の字を当てたもの 45，字形として記録したもの 19）。
   スクリプトに直書きすれば，なぜその字にしたのかが失われる。
3. **無い字は，似た字で置き換えない。** 字形として記録し，平文では私用領域の
   **1 文字**で表す（1 文字でないと語数も KWIC も崩れる）。いちばん近い標準の字が
   立つものにだけ，それを併記する（屋号記号「丸にナ」→ ㋤）。
4. **分からないものは，分からないと書く。** `〓` にして件数を出す。v1 の `※` と
   違うのは，**何が欠けたかが注記として残り，数えられる**ことである。
5. **作品ごとに数え，検査で止める。** `03` の変換リポートと `04` の正規化リポートに
   作品別の件数を出し，`99_validate.py` が未解決を報告する。

### 3.5 対応策 — 使う人・増やす人がすること

**分析に使うとき**

- `data/xml/conversion_report.csv` の `gaiji_resolved`・`gaiji_supplement`・
  `gaiji_glyph`・`gaiji_unresolved` を，**作品ごとに**見る。合計だけで済ませない
- 論文には，復元した件数と未解決の件数，編者が同定した字があることを書く
- 編者が当てた 94 箇所は推定である。その字が論点に関わるときは，
  `gaiji_supplement.tsv` の根拠を読み，できれば底本に当たる
- 外字の多い作品（『道標』『伊沢蘭軒』『飛騨の怪談』『即興詩人』）を含む比較では，
  **その作品を外した結果も並べる**。結論が変わるなら，外字の扱いが効いている
- 字形として記録した字（屋号記号・合略仮名）は，解析器には未知の記号である。
  未知語の一覧に出ても，前処理の失敗ではない

**作品を増やすとき**

1. `03_aozora2xml.py` を実行し，変換リポートで `gaiji_unresolved` が 0 でない作品を見る
2. 未解決の注記を読む。面区点の読み違いか，説明だけの注記か，外字でない注記かを分ける
3. 説明だけの注記は，構成（「巾＋兌」）から候補の字を挙げ，**本文の文脈に合うか**を
   確かめる。合えば対照表に 1 行足し，`evidence` 列に根拠を書く
4. Unicode に無ければ `kind=glyph` で字形として登録する。似た字を当てない
5. 同定できなければ，そのまま `〓` で残す。**無理に当てた字は，欠けた字より害が大きい**
   （欠けた字は数えられるが，誤った字は正しい語として数えられてしまう）
6. `03b`（分冊の結合）と `04`（正規化）のあとで，もう一度，作品ごとの件数を見る

### 3.6 面区点からの復元の仕組み

青空文庫の外字注記は JIS X 0213 の **面-区-点**（または Unicode）を与える。

```
※［＃「广＋(炎/鳥)」、第4水準2-81-40］
                      面 区  点
```

EUC-JIS-2004 の符号化規則で Unicode に確定的に変換できる。

| 面 | バイト列 |
|---|---|
| 面1 | `0xA0+区, 0xA0+点` |
| 面2 | `0x8F, 0xA0+区, 0xA0+点` |

実装は `lib/aozora.menkuten_to_char()`。検証済みの対応例：

| 注記 | 復元 |
|---|---|
| 第3水準1-14-22 | 侔 |
| 第3水準1-15-25 | 噲 |
| 第3水準1-84-7 | 噓 |
| 第4水準2-78-35 | 泖 |
| 第4水準2-81-40 | 㽷 |

復元できない場合は `<g ref="unresolved" n="注記本文"/>` として保存し，
解析ストリームでは `〓` に置換して**数えられる状態**にする。
（v1 では `※` が残るだけで，何が失われたか分からなかった）

**v1 で失われていた例**

| 作品 | v1 の状態 | 原文 |
|---|---|---|
| 徳冨蘆花『不如帰』 | `合 ※ の 式` | 合巹（ごうきん）の式 |
| 藤村『夜明け前』 | `檜木、椹、明檜、高野槇、※` | 鼠子（ねずこ）＝木曾五木 |
| 岡本かの子『生々流転』 | `掻き ※ り ながら` | 毟（むし）り |

## 4. 踊り字（iteration marks）

| 記号 | 処理 | 理由 |
|---|---|---|
| `々` | **展開しない** | UniDic に語彙素として登録済み（人々・時々・我々） |
| `ゝ` | 直前の平仮名を反復（直前が濁音なら清音化） | UniDic 未登録 |
| `ゞ` | 直前の平仮名を濁音化して反復 | 同上 |
| `ヽ` `ヾ` | 片仮名版 | 同上 |
| `／＼` `〳〵` | 直前の仮名連続（2–4字）を反復 | 同上 |
| `／″＼` `〴〵` | 同上・濁音化 | 同上 |
| `〃` | `<seg type="ditto"/>` として除外 | 表・リスト内の同上記号 |

### くの字点の曖昧性

くの字点は「直前の何字を繰り返すか」が原理的に決まらない。
本パイプラインは**直前の仮名連続（最大4字）**を単位とするヒューリスティクスを
用い，機械推定であることを記録に残す。誤展開が疑われる箇所は
`normalise_report.csv` の `kunoji_expanded` を手がかりに点検する。

### なぜ正規化が必要か

v1 における仮名踊り字の偏在（546箇所が7ファイルに集中）は，
**文体差ではなく底本の正書法差**である。

| ファイル | ゝ | ゞ | ヽ | ヾ | 文字遣い |
|---|---:|---:|---:|---:|---|
| 藤村『破戒』 | 218 | 0 | 0 | 0 | 新字旧仮名 |
| 藤村『夜明け前』『家』『新生』『千曲川』 | 0 | 0 | 0 | 0 | 新字新仮名 |
| 岡本かの子『生々流転』 | 8 | 183 | 0 | 0 | 新字新仮名 |
| 石川啄木『鳥影』 | 2 | 5 | 66 | 2 | 新字旧仮名 |

正規化しないと，同一著者内でも底本差が文体差として検出される。

## 5. 文字の正規化

| 対象 | 処理 | 備考 |
|---|---|---|
| 全角ラテン文字・全角数字 | NFKC で半角化 | `Ｂ・Ｄ` → `B・D` |
| 仮名・約物 | **NFKC をかけない** | `「」` が変形するため |
| 波ダッシュ `〜` U+301C | 全角チルダ U+FF5E に統一 | 環境依存の異体 |
| 全角マイナス U+2212 | ASCII ハイフンに統一 | — |
| 連続空白・改行 | 整理 | — |

**漢数字と算用数字は統一しない。** 「十九年」と「19年」は書記上の選択であり，
文体の指標になりうる。統一すると情報が失われる。
（`海野十三『敗戦日記』`366箇所，`火星兵団` 126箇所の算用数字は，
 それ自体が日記／少年向け新聞小説という媒体の特徴である）

## 6. 形態素解析

| 項目 | 決定 |
|---|---|
| 辞書 | **近現代口語小説UniDic（`unidic-novel` v202512）**。2026-09-22 決定（`docs/dictionary_comparison.md` §10） |
| 検算用の辞書 | 近代文語UniDic（`unidic-kindai-bungo` v202512）。A_文語体の助動詞率の確認にのみ使う |
| 使わない辞書 | 現代書き言葉（cwj）。同じ 111 点で未知語率が novel の 3.9 倍（0.66% 対 0.17%） |
| 単位 | 短単位（SUW） |
| 分析語形 | `lemma_key`（下記の規則） |
| 同形異義接尾辞 | 既定で除去（`私-代名詞` → `私`） |
| 補助記号・空白 | 既定で除外（`--keep-punct` で保持可） |

### `lemma_key` の規則

```
固有名詞（pos1=名詞, pos2=固有名詞） → orthBase（なければ表層形）
それ以外                            → lemma（なければ orthBase → 表層形）
```

UniDic の `lemma` は異綴形（噓／嘘，云う／言う）を統合するので通時比較に向くが，
**固有名詞では片仮名の読みになる**（渋江 → シブエ）。上の規則で回避する。

### 出力する3系統

| ファイル | 内容 | 用途 |
|---|---|---|
| `tokens_lemma/` | 全品詞の語彙素 | 文体計量・word embedding |
| `tokens_surface/` | 表層形 | 表記の変化を扱うとき |
| `tokens_content/` | 名詞・動詞・形容詞・副詞の語彙素 | トピックモデル |

`tsv/` には1行1形態素で全素性を残す。**後から別の方針で作り直せる**ようにする。

### 未知語率は表記別に見る

未知語率は**仮名遣い・字体と強く相関する**。下は参考として，**現代語辞書
cwj で測った値**（108点）を示す。本番の辞書 `unidic-novel` では水準が大きく
下がる（全体で 0.66% → 0.17%）が，「表記の群ごとに見る」という読み方は
変わらない。

| 表記 | 件数 | 中央値 | 最大 |
|---|---:|---:|---:|
| 新字新仮名 | 85 | 0.22% | 1.44% |
| 新字旧仮名 | 19 | 0.61% | 1.81% |
| 旧字旧仮名 | 4 | 1.81% | 2.95% |

> 自分の値は `data/tokens/tokenise_report.csv` を `kana_orthography` で
> 群分けして求めること。`unidic-novel` では残る未知語の
> 大半がカタカナ外来語になるため，**未知語率は「正書法の乱れ」ではなく
> 「外来語の密度」を測る指標に変わっている**
> （`docs/dictionary_comparison.md` §11）。

**全体の中央値と比べてはいけない。** 旧字旧仮名の作品が軒並み警告になり，
本当の異常が埋もれる。`99_validate.py` は `kana_orthography` で群に分け，
**同じ表記の仲間の中で外れているか**を見る。

### 表記は時代と交絡している

旧字旧仮名5点の初出年は 1892・1895・1910（2点）・1913 で，すべて大正初年（1913 年＝大正2年）までである。
つまり「時代が下ると未知語率が下がる」という観察は，**言語の変化ではなく
底本の表記方針を測っている**おそれがある。通時比較では

1. `kana_orthography` を共変量としてモデルに含める（メタデータの列にある）
2. 旧字旧仮名を除いた場合と含めた場合で結果を比べる

の2つを必ず行うこと。表記を理由に個別の作品を除外するのは，**同じ基準を
既存作品にも当てられるときに限る**（『即興詩人』154,451語も旧字旧仮名である）。

### 採否を数値で決めるとき

新規候補が旧字旧仮名しか無い場合（増補した長塚節『土』がそうであった）は，取得して
未知語率を測ってから決める。目安:

| 未知語率 | 判断 |
|---|---|
| 〜2.95%（既存の旧字旧仮名の最大値まで） | 採用。既存作品と同じ扱い |
| 2.95〜4% | `unknown_words.csv` を見る。方言語彙・固有名詞なら**内容**であって雑音ではない。採用してよい |
| 4% 超 | 見送る。解析が信用できない |
