# コーパス設計 — 何を目指し，何が入らなかったか

近代日本文学コーパス（JLit, 青空文庫由来・1872–1959）の**設計の記録**である。
目標値は `config/design_targets.yaml`，現状との差は
`python3 scripts/check_balance.py` が出す。この文書は，その数値が
**なぜその値なのか**と，**埋まらなかった穴**を書き残すためにある。

読む順序は，**§0 出発点（v1 の長所と短所）→ §1 母集団と標本 → §2 設計目標 →
§3 見直しと増補 → §4 残った制約**である。改善の提案（§2・§3）は，§0 の
診断から出ている。§0 を飛ばすと，目標値の理由が分からない。

> ⚠ 論文・発表でこのコーパスを使うときは，§4「制約」の記述をそのまま
> 引用できる形にしてある。**埋まらなかった穴を書かずに結果だけを示すのは，
> 代表性の主張として不誠実である。**

## 0. v1 コーパスの振り返り — 出発点を率直に書く

設計の見直しは，**手元にあったコーパスを測り直すこと**から始まった。v1 を
「欠陥のある旧版」として片づけると，なぜ §2 の目標がその値なのか，なぜ §3 の
増補がその順序なのかが分からなくなる。ここでは v1 の長所と短所を同じ基準で
並べる。数値はすべて `metadata/corpus_metadata_v2.csv`（v1 の 64 ファイルを
記述した表）と `metadata/diagnostics_v1.csv`，`logs/validation_v1.csv` から出る。
作品ごとの詳細は `docs/representativeness_report.md` にある。

### 0.1 v1 とは何であったか

| | |

| 作家 | 21 人（男性 17・女性 4） |

### 0.2 v1 が持っていたもの（長所）

1. **作品単位の統計に耐える長さ。** 64 点すべてが 3 万語以上で，中央値は 6 万語。
   TTR や Delta のように標本の大きさに敏感な指標を，作品単位でそのまま測れた。
   v3 は短篇を加えたので，最短 3,337 語・最長との比は 141 倍に広がっている
   （v1 は 16.5 倍）。**これは増補で失ったものである。**
2. **長篇が厚い。** 長篇小説（`form=novel`）が 33 点・語数の 66.9 % を占める。
   完結している作品は 59 点（92 %）。
3. **昭和期は十分に厚い。** 昭和戦前 26 点・256 万語，昭和戦後 16 点・137 万語。
   昭和期の内部の比較（戦前と戦後，純文学と大衆文学）には，v1 のままでも足りた。
4. **語りの人称が均衡している。** 一人称 28 点・三人称 30 点。
5. **文化的な位置づけに幅がある。** 正典 36 点・中間 13 点・大衆 14 点・記録 1 点，
   児童向け 7 点。探偵小説 8 点とプロレタリア文学 4 点を含み，
   「文学史の正典だけ」のコーパスではない。
6. **女性作家の語数比は 24.4 %。** 現行 v3 の 19.6 % より高い
   （ただし下の短所 4 を見よ）。
7. **すぐ使える。** 分かち書き済みなので，頻度表も word2vec も前処理なしで動いた。

4. **女性作家は 4 人・11 点で，最も早い作品が 1924 年。** 語数比 24.4 % の

5. **ジャンルと形式が小説に偏る。** Fiction が 54 点（84 %），NDC では小説

6. **表記の幅が狭い。** 新字新仮名 57 点・新字旧仮名 7 点で，旧字旧仮名は 0 点。

#### (b) 本文の欠陥

| 欠陥 | 規模 | 何が起きるか |
|---|---|---|

| 外字が `※` のまま失われている | 592 箇所・21 ファイル | 語が切れる（「合巹」→「合／※」）。元の字は復元できない |
| 奥付・入力者注の混入（『敗戦日記』） | 約 570 語 | 「入力」「校正」「青空文庫」が本文の語として数えられる |
| 分冊の欠落（『家』は下巻のみ） | 1 点 | 作品として不完全 |
| 仮名踊り字の扱いが不統一 | 546 箇所・7 ファイル | 文体差ではなく底本の表記差が，語彙の差として出る |
| ルビが除去済み | 全ファイル | 除去か保持かを選び直せない（不可逆） |

#### (c) 記録が無いこと

1. **分かち書きの辞書と版が記録されていない。** 同じ本文の 2 ファイルで分割が
   食い違い，別の辞書の混入も疑われる（`representativeness_report.md` §6.1）。
   **どう切ったかが分からない語数は，別の辞書の語数と比べられない。**
2. **語彙素も品詞も無い。** 表記の違う同じ語（云う／言う）をまとめられず，
   品詞で絞ることも，機能語だけを取り出すこともできない。
3. **メタデータに典拠が無い。** 初出年に底本の刊年が入っていた行がある
   （『潜航艇「鷹の城」』が 1977 年。初出は 1935 年）。`genre` は英語・日本語・
   誤綴が混在し，`ndc` は番号ではなくラベル，`brow` は high/low の二値に
   児童書とノンフィクションが押し込まれていた。
4. **元の XHTML との対応が無い。** 欠陥が見つかっても，原文に戻って直す道が無かった。

### 0.5 ここから導いた改善の方針

短所を 3 つの層に分けたのは，**直し方が違う**からである。(b) と (c) は作り直せば
直る。(a) は作品を足さなければ直らず，しかも足せる作品には限りがある（§1）。

| v1 の短所 | 改善の提案 | 行った場所 | v3 での結果 | 残ったもの |
|---|---|---|---|---|
| 本文の欠陥（取り違え・外字・奥付・分冊） | 青空文庫の XHTML から**全点を作り直す**。外字は面区点から復元し，分冊は結合する | Step 2，§3.7 | 取り違え・混入は解消。外字は未解決 0 箇所（復元 2,733，編者が当てた字 94，符号点の無い字 94） | — |
| 辞書と版が不明 | 辞書を 4 つ比べて 1 つに決め，版と設定を記録する | Step 3，`dictionary_comparison.md` | `unidic-novel` v202512。未知語率 0.16 % | 辞書を替えれば語数は変わる |
| 語彙素・品詞が無い | UniDic で解析し直し，表層形・語彙素・品詞を持つ | Step 3 | KWIC・品詞による絞り込みが可能に | — |
| メタデータに典拠が無い | 初出年を書誌から取り直し，各列に典拠を付ける | Step 2，§3.5 | `year_source` で出どころを区別 | 編者の記入が分析対象で 43 件残る |
| 1899 年以前が 3 点・4.6 % | 明治前期〜中期を優先して増補する | §3.3 | 20 点・11.9 %。`A_文語体` は 1 点から 16 点へ | 明治前期は 4 点・13.9 万語（§4-1） |
| 時代区分が作家と重なる | 区分内の最大作家を 40 % 以下にする目標を置く | §2，§3 | 6 区分のうち 4 区分で達成 | 明治前期の三遊亭円朝 53 %（§4-1），昭和戦後の宮本百合子 42 %（§4-6） |
| 少数の作家への集中 | 1 作家 12 % 以下。漱石を増補して鴎外と均衡させる | §3.2–3.4 | 作家 21 人から 48 人へ。上位 5 人は 53.9 % から 46.4 % へ | 島崎藤村 12.4 %（§4-5） |
| 女性作家が 4 人・1924 年以降 | 各区分に女性作家 2 人以上 | §3.3 | 10 人・23 点。明治期に 4 人 | 語数比は 24.4 % から 19.6 % に**下がった**（§3.4，§4-2） |
| 戯曲・韻文が 0 点 | 戯曲と随筆・評論を加える | §3.3 | 戯曲 3 点，随筆・評論 12 点 | 韻文は入れていない |
| 旧字旧仮名が 0 点 | 表記を理由に除外しない | `encoding_guidelines.md` | 5 点 | 表記は時代と交絡する |

この表の右端の列が，§4「埋まらない穴」である。**改善は短所を消したのではなく，
測れる形にして，残ったものを明示できるようにした**。そして長所の 1（作品が
みな長い）は，短篇を加えたことで失われた。増補は得るものだけではない。

## 1. 母集団と標本

母集団は「1872–1959 年に日本語で書かれ，刊行された散文」である。
標本はそのうち**青空文庫が電子化し，著作権保護期間の満了したもの**に限られる。

この二重の絞り込みが，以下のすべての偏りの源にある。

- **保護期間**：1968 年以降に没した作家は原則として入らない。戦後の作家は，
  早世した者（織田作之助 1947・横光利一 1947・太宰治 1948・宮本百合子
  1951・坂口安吾 1955）に事実上限られる。
- **電子化の選択**：青空文庫の所蔵は，入力者の関心を反映する。明治前期の
  散文は薄く，探偵小説・児童向け読物は厚い。

**標本の偏りは，我々の設計の失敗であると同時に，利用できる資料の性質でもある。**
両者を区別して書くこと。

## 2. 設計目標

`config/design_targets.yaml` に機械可読な形で置いてある。

| 何を | 目標 | なぜ |
|---|---|---|
| 1作家の語数比 | 12 % 以下 | G² も PCA も word2vec も「誰が書いたか」を見ない。2割を占める作家がいれば，その文体が「時代の特徴」として出る |
| 1作品の語数比 | 8 % 以下 | 長篇1点が時代を代表してしまう |
| 区分内の最大作家 | 40 % 以下 | 時代スライスが一人の作家になっていないか |
| 1スライスの語数 | 50 万語以上 | 少ないスライスのモデルだけ語彙も近傍も貧しくなる |
| スライスの最大/最小 | 3 倍以内 | 「時代が違う」のか「標本が少ない」のかを区別するため |
| 各区分の女性作家 | 2 人以上 | 性別と時代の交絡を減らす |
| 夏目漱石 | 9 点以上 | 森鴎外 7 点との均衡（下記 §3） |

数値の根拠は「この値を超えると解釈が壊れる」という経験則であり，先行研究に
よる定数ではない。**変えてよい。ただし変えたら記録すること**（目標表を
書き換え，`logs/` に日付つきの写しを残す）。

## 3. 2026-09-26 の設計見直し

§0 の診断を受けて，まず 64 点の本文を XHTML から作り直し，明治期の作品・
女性作家・戯曲・随筆を加える第一次の増補を行った（64 点 → 101 点）。
この節は，**その 101 点を §2 の目標に照らして測り直した記録**である。
第一次の増補で短所の多くは軽くなったが，測り直すと別の偏りが見えた。

### 3.1 測ったこと

`merged` / `too_short` の行を除く）。

| 2 明治中期（1887–99） | 14 | 703,600 | 11.3 % | 森鴎外 24 % | 1 人 |
| 3 明治後期（1900–11） | 15 | 674,022 | 10.9 % | 島崎藤村 37 % | 2 人 |

作家の上位：宮本百合子 12.1 %（4点）／森鴎外 11.8 %（7点）／島崎藤村

### 3.2 見つかった4つの偏り

1. **漱石 4 点・4.7 % に対し鴎外 7 点・11.8 %。** 文学史的な位置づけに
   対して不均衡である。鴎外の語数は史伝『伊沢蘭軒』(316k)・『渋江抽斎』
   (107k) と翻訳『即興詩人』(162k) の長篇3点で作られており，**点数以上に
   語数で効いている**。
2. **明治前期は3点すべて福沢諭吉。** これは時代区分ではなく一人の作家である。
3. **昭和戦後は語数の 50 % が宮本百合子，59 % が女性。性別と時代が
   交絡している。** 「女性作家の語彙」として出てくるものの相当部分は
   「戦後の語彙」でありうる。
4. **明治前期〜中期の女性作家は樋口一葉ただ1人。**

### 3.3 決めた手当て

| 穴 | 手当て | 効き方 |
|---|---|---|
| 漱石の不足 | 『吾輩は猫である』(1905)・『それから』(1909)・『門』(1910)・『行人』(1912)・『道草』(1915) の5点 | 4 → 9 点。うち2点は大正期なので**大正の鴎外 32 % も同時に薄まる** |

### 3.4 増補の結果（2026-09-26）

124 点を取得・解析し，メタデータを作り直した（分析対象 117 点・754 万語。
延べ 798 万語のうち，合本・分冊・短すぎる行を除いた数）。

| | 増補前 | 増補後 | 目標 |
|---|---:|---:|---|
| 点数／語数 | 101 点・621 万 | **117 点・754 万** | — |
| 夏目漱石 | 4.7 %（4点） | **11.8 %（9点）** | 12 % 以下・9点 ✓ |
| 森鴎外 | 11.8 % | 9.5 % | ✓ |
| 宮本百合子 | 12.1 % | 9.9 % | ✓ |
| 最大の作品（『道標』） | 7.3 % | 6.0 % | 8 % 以下 ✓ |
| 大正の鴎外 | 32 % | **26 %** | 40 % 以下 ✓ |
| スライスの最大/最小 | 3.2 倍 | **2.2 倍** | 3 倍以内 ✓ |
| 昭和戦後の宮本 | 50 % | 47 % | 40 % 以下 ✗ |
| 女性の語数比 | 23.3 % | **19.3 %** | 20 % 以上 ✗ |

**狙った効果は出たが，副作用が出た。** 増補した 133 万語のほとんどが男性
作家（漱石 60 万・長塚節・泉鏡花・田山花袋・徳田秋声・有島武郎・円朝）
だったため，**分母が増えて女性比が 23.3 % から 19.3 % に下がった**。点数は
20→21，作家は 9→10 人と増えているのに，比率は落ちている。
「増やしたことで却って偏る」——目標を数値で置いていなければ，
この低下は誰にも見えなかった。

もう一つ。明治後期の最大作家は**藤村 37 % から漱石 39 % に替わった**だけ
とも言える。集中は解消されたのではなく，移動した。次の増補では，
この区分に漱石以外を足す必要がある。

その後，林芙美子の2点を加えて（§4.1），現行の v3 は**分析対象 119 点・
812 万語**（8,116,912 語）である。現行の値は，女性の語数比 19.6 %，
昭和戦後の宮本百合子 42 %，島崎藤村 12.4 %，最大の作品（『夜明け前』）5.8 %。

### 3.5 時代区分と初出年の食い違い（同日発見）

`period` は `year_first` の関数であるのに，**保存された値が古いまま残って
いた行が2件**あった。

| 作品 | 初出年 | 表の区分 | 正しい区分 |
|---|---|---|---|
| 有島武郎『或る女』 | 1919 | 明治後期 | 大正 |
| 水野仙子『四十余日』 | 1910 | 大正 | 明治後期 |

『或る女』は，索引が拾った 1911 年（『或る女のグリンプス』連載開始）で
明治後期に入ったあと，編者が初出年を 1919 に直したが，区分は取り残された。
**例外は出ない。** 大正の作品が明治後期の集計に混じり，時代のキーワードも
通時モデルも，静かに汚れる。

`00_extend_metadata.py` が**毎回初出年から引き直す**ように改め，直した行を
報告するようにした。`check_balance.py` も食い違いを検査する。

### 3.6 `narration` の `mixed` の境界（同日決定）

増補した『行人』をどう分類するかを機に，統制語彙の境界を決めた。
**地の文（matrix）の人称で決める。** 長文の書簡・手記・日記が挿入されて
いても，それだけでは `mixed` にしない——挿入部は
`<quote type="embedded">` として分離され `data/plain/embedded/` に
切り出されるので，語りの交替はそちらの側で扱う。**一つの事実は一か所に
記録する。**

したがって『こころ』（下巻 51 % が遺書）も『行人』（末尾が H の書簡）も
`first` のままとする。`mixed` は地の文そのものが交替する作品・枠物語・
作品集に限る（『光と風と夢』『青蛙堂鬼談』『少女地獄』の3点）。

定義は `01_build_workbook.py` の codebook と用語集に明記した。

### 3.7 外字の扱い — 五つの由来（2026-09-27 決定）

外字の復元は，再構築でいちばん手間のかかった工程である。外字を含むのは
122 作品のうち 66 作品，合わせて 2,921 箇所・451 種で，機械的に復元できたのは
そのうち 2,733 箇所である。残りは 1 つずつ注記と本文を読んで判断した。
なぜ重要か，なぜ難しいか，理想と現実の解決，使う人がすべきことは
`docs/encoding_guidelines.md` §3 にまとめた。ここには決定の経緯を記す。

増補後の本文に未解決外字が 130 箇所残っていた。**由来の違うものを同じ顔で
書かない**という方針で整理し、**0 箇所**にした。

| 由来 | 何か | 本文での書き方 | 箇所 |
|---|---|---|---:|
| 面区点からの復元 | JIS X 0213 の面区点が注記にある | `<g ref="1-84-7">噓</g>` | 2,733 |
| 編者が当てた字 | 符号点の記されていない字形説明から同定 | `<g ref="supplement" resp="editor">帨</g>` | 94 |
| 符号点の無い字 | Unicode に存在しない | `<g ref="#id"/>` ＋ `charDecl` | 94 |
| 外字でない注記 | 底本についての編者注 | 外字として数えない | 3 |
| 未解決 | 実体が不明 | `<g ref="unresolved">` → `〓` | **0** |

同定は**編者の判断**なので `config/gaiji_supplement.tsv` に根拠（`evidence`
列）とともに置く。スクリプトに直書きすれば「なぜその字にしたのか」が失われる。
64 件を登録した。

**注記が符号点を記していないことと、Unicode に符号点が無いことは別である。**
当初これを混同し、「JIS X 0213 に在る字は青空文庫が面区点を出すはずだから
候補として不適合」と判断したが、これは誤りであった。面区点注記が導入される
前に登録された古いファイル（『浮雲』『金色夜叉』『福翁自伝』『怪談牡丹灯籠』）
は、JIS の範囲内の字でも説明と底本のページ・行だけで注記している。

#### 屋号記号 — 最大の階級（48箇所）

商家を指す印で、近代小説では**固有名詞として**使われる。注記では `＜` が
「囲む」、`┐` が曲尺すなわち「カネ」、`ひとがしら` 𠆢 が山形すなわち「ヤマ」。

| 印 | 作品 | 箇所 |
|---|---|---:|
| カネに△ | 小林多喜二『不在地主』 | 29 |
| 丸にナ／ヤマにナ | 島崎藤村『家』 | 8 / 8 |
| カネに辰 | 『不在地主』『工場細胞』 | 各 1 |
| カクに万 | 島崎藤村『夜明け前』 | 1 |

**漢字に置き換えない。** 『不在地主』の 29 箇所は一つの商家を一貫して指して
おり（「〓荒物屋の主人」「大貿易商である〓」）、印そのものが意味を担う。
字形として記録し、**いちばん近い標準字が立つものにだけ** TEI の
`<mapping type="standard">` を添える（丸にナ → ㋤）。本文は `<g ref="#id"/>`
のままだから**屋号記号であったことは失われず**、平文の派生物だけが標準字に
なる。私用領域の文字は形態素解析器から見れば未知の記号でしかないので、
代わりが立つなら立てる——ただし `感嘆符三つ` を `！！！` と三文字に展開する
ような、**一字であるという情報を壊す**置き換えはしない。

同じ方針を変体仮名にも使った。Unicode の変体仮名は字母ごとに符号化されて
いるが注記は字母を示さないので特定できない。平文には通常の仮名を当て、
変体仮名であったことは `charDecl` に残す。

#### 同じ日に見つかった二つの欠陥

**`03b` が `charDecl` を結合していなかった。** `03` は字形の定義を巻ごとに
`teiHeader` へ置くので、本文だけ結合すると 2 巻目以降の `<g ref="#id"/>` が
定義を失う。『家』下巻の屋号記号 8 箇所が `〓` になっていた。`03` の報告は
全ファイル「未解決 0」であり、**合計だけを見ていたら気づかなかった**。

**注記が `※` を引用していることがある。** `［＃罫内の「※」は…］`
`［＃「貳朱は」は底本では「※［＃…］」］` はいずれも底本についての編者注で
あって字形の説明ではない。弾かないと本文の `※` が外字に化ける。字形の説明に
`※` が現れることはないので、それを目印に弾く（`gaiji_not` に計上）。

## 4. 埋まらない穴（論文に書くべき制約）

以下はいずれも**増補では解決しない**。手当てを尽くした上でなお残る制約として，
結果とともに明示すること。

1. **明治前期（〜1886）は単独の時代区分として成立しない。** 増補前は
   3点・6.7 万語で，全点が福沢諭吉であった。増補で足せるのは三遊亭円朝
   『怪談牡丹灯籠』(1884) 1点のみで（下記），現行でも4点・13.9 万語にとどまる。本研究では明治中期に畳んだ5区分（`period5`）で
   学習し，6区分は記述統計にのみ用いた。**区分の根拠が文学史ではなく
   標本の量であることを明記する。**

   **2026-09-26 の確認**：明治前期の補強に挙げた次の3点は，青空文庫の
   書誌索引（19,502 件）を作品名で検索して**不在を確認**した。いずれも
   保護期間はとうに切れており（中村正直 1891 年没・福沢諭吉 1901 年没・
   若松賤子 1896 年没），**未電子化**である。

   | 作品 | 意義 | 状態 |
   |---|---|---|
   | 福沢諭吉『文明論之概略』(1875) | 明治初期の漢文脈論説の基準点 | 未電子化 |
   | 中村正直『西国立志編』(1871) | 幕末明治の翻訳文体（漢文訓読体）の基準点 | 未電子化 |
   | 若松賤子『小公子』(1890) | 女性訳者による言文一致。性別・ジャンル・文体の三重の空白を同時に埋めるはずだった | 未電子化 |

   **「入れたいが入れられない」の理由は，保護期間だけではない。** 明治初期の
   散文は，著作権が切れていても電子化されていないことが多い。青空文庫を
   標本抽出の枠に使う以上，**電子化の偏りをそのまま受け継ぐ**。これは
   本コーパスに限らず，青空文庫由来の全コーパスに共通の制約である。
2. **女性作家の語数比は 20 % 前後で頭打ちになる**（現行 19.6 %）。 保護期間中のため
   入れられない作家に，野上弥生子・平林たい子・佐多稲子・尾崎翠がいる。
   公開されている女性作家の作品は短篇・評論が中心で，語数では稼げない。
   したがって**性別の比較は，語数比の等価性を前提にできない**。
3. **昭和戦後は，早世した作家に偏る。** 1968 年以降に没した作家が原則
   入らないため，「戦後文学」の標本としては代表性が低い。
4. **ジャンルは Fiction に偏る**（分析対象 119 点で 96 : 23）。随筆・評論・日記は薄い。

5. **島崎藤村が語数の 12.4 % を占める**（上限 12 %）。『夜明け前』4巻 47 万語・
   『新生』21 万語・『破戒』12 万語からなる。いずれもこのコーパスの目的
   （言文一致から自然主義への文体の推移）に不可欠で，外せない。
   **収録では下げきれない集中**として記録し，分析時に均す
   （`06 --max-per-author` ／ `08 --balance`）。

   なお，この 12.6 % は 2026-09-26 に**分冊を結合して初めて正しく測れた**
   数字である。それ以前は『夜明け前』第一部上・『家』上巻しか集計に
   入っておらず，藤村は過少に見えていた（§3.5 の前段）。

6. **昭和戦後の宮本百合子が 42 % 前後に残る**（上限 40 %）。林芙美子2点の
   増補で 47 % から下がるが，上限は割らない。**戦後は著作権の満了した
   作家が少なく**，薄める材料が尽きている。

   ⚠ したがって**「戦後の語彙」として観測されるものには，宮本百合子の
   文体が強く混じる**。戦後を論じるときは，作家を統制した比較
   （Step 7 の doc2vec）を併せて示すこと。

### 4.1 増補をどこで止めたか（2026-09-26）

女性の語数比 20 % と戦後の宮本 40 % を**同時に満たす**には，太宰治・坂口安吾・
岡本かの子・樋口一葉を含む8点（約 32 万語）の追加が必要だった。しかし
それは「目標の数値を満たすために作品を選ぶ」ことになる。

**採ったのは林芙美子『浮雲』(1949–51)・『晩菊』(1948) の2点のみ**である。
戦後の女性作家の長篇という一点で，2つの穴に同時に効く。残る不足
（宮本 42 %）は上に制約として明記し，分析時に均す。

> **目標値は，作品を選ぶ理由ではなく，選んだ結果を測る物差しである。**
> 数値を満たすことが目的化すれば，コーパスは「指標のために作られた標本」に
> なる。埋まらない穴は，埋めずに書く。

## 5. 収集による均衡と，分析時の均衡

**両方が要る。** 収集で下げきれない集中は，分析の側で均す。

| | 手段 | どこで |
|---|---|---|
| 収集 | 増補・上限の設定 | `corpus_manifest.tsv`／`design_targets.yaml` |
| 分析 | スライスの語数を揃える | `08_word2vec_diachronic.py --balance` |
| 分析 | 1作家あたりの上限 | `06_build_datasets.py --max-per-author` |
| 分析 | 作家を統制した比較 | Step 7（doc2vec・交絡の分離） |

⚠ **分析時の均衡化は，収集の偏りを消さない。** 捨てているだけである。
捨てた量は必ず報告すること（各スクリプトが落とした件数を出す）。

## 6. 増補したあとに走らせるもの

増補は**測り直しまで済んで完了**である。途中で止めると，メタデータの実測値
（語数・TTR・文語率）が古い本文のものになる。

```bash
# 0) 索引を最新にし，マニフェストが解決できるか先に確かめる
python3 scripts/02_fetch_aozora.py index --out data/aozora
python3 scripts/02_fetch_aozora.py resolve --manifest config/corpus_manifest.tsv --out data/aozora

# 1) 取得（1件1秒。未解決行は data/aozora/unresolved.csv に出る）
python3 scripts/02_fetch_aozora.py works --manifest config/corpus_manifest.tsv --out data/aozora

# 2) XML 化 → 正規化 → 形態素解析
python3 scripts/03_aozora2xml.py --in data/aozora/xhtml --log data/aozora/fetch_log.csv --out data/xml
# 03 の直後に必ず。03 は毎回 XML を作り直すので，03 のたびに結合は解ける
python3 scripts/03b_merge_volumes.py --xml data/xml --config config/merge_volumes.tsv
python3 scripts/04_normalise.py --in data/xml --out data/plain --config config/pipeline.yaml
python3 scripts/05_tokenise_unidic.py --in data/plain/full --out data/tokens \
    --lemma-policy mixed --expect-dict unidic-novel

# 3) メタデータを作り直す（実測値もここで測り直す。period5 もここで入る）
# **_local に書く。** 配布版 corpus_metadata_v3.csv は git 管理下なので，
# そこへ再生成すると git pull のたびに止まる。測った版と配った版は別の名前に
python3 scripts/00_extend_metadata.py \
    --meta metadata/corpus_metadata_v2.csv \
    --fetch-log data/aozora/fetch_log.csv \
    --candidates metadata/expansion_candidates.csv \
    --tokens data/tokens/tokens_surface --remeasure-all \
    --out metadata/corpus_metadata_v3_local.csv

# 4) データセットと検算
python3 scripts/06_build_datasets.py --tokens data/tokens/tokens_content \
    --meta metadata/corpus_metadata_v3_local.csv --out data/datasets \
    --chunk 2000 --max-chunks 40
# **06 に渡したものと同じものを渡すこと。** completeness は「ある本文について
# の判断」であって作品の永久の属性ではない。v2 の completeness は v1 のテクスト
# についての記述なので，渡すともう存在しない欠陥を報告し続ける。99 は 06 の
# dataset_provenance.json を読んで食い違いを FATAL にするので，取り違えても
# 気づける
python3 scripts/99_validate.py --corpus data/plain/full \
    --meta metadata/corpus_metadata_v3_local.csv \
    --tokenise-report data/tokens/tokenise_report.csv --out logs/validate_v3.csv
python3 scripts/check_balance.py

# 5) 配布版を更新する（クローンで検証した版をマスターへ写してコミットする）
# cp metadata/corpus_metadata_v3_local.csv <マスター>/metadata/corpus_metadata_v3.csv
```

**`02 resolve` を先に走らせること。** 解決できなかった行は
`unresolved.csv` に理由つきで出るので，**そこで見送りを決める**。
見送った作品は §4 の制約に書き足すこと。

2026-09-26 の実行結果：**127 行中 124 が解決，未解決 3**。未解決の3点は
いずれも未電子化のため，マニフェストから外した（§4）。
「著者が未登録」の診断は，**保護期間中とは限らない**（未電子化・表記ゆれの
可能性もある）。**作品名で索引を引いて区別すること。**

`02` は1件あたり1秒の間隔を置く（`config/pipeline.yaml` の
`sleep_seconds`）。**この値は下げないこと。**

増補後は，**新しい作品の初出年・ジャンル・語り手を人の目で確かめる**。
判断の要る列は `metadata/editorial_expansion.csv` に書けば
`00_extend_metadata.py` が拾う（`needs_review` が立った行が対象）。
