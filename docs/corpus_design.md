# コーパス設計 — 何を目指し，何が入らなかったか

近代日本文学コーパス（JLit, 青空文庫由来・1872–1959）の**設計の記録**である。
目標値は `config/design_targets.yaml`，現状との差は
`python3 scripts/check_balance.py` が出す。この文書は，その数値が
**なぜその値なのか**と，**埋まらなかった穴**を書き残すためにある。

> ⚠ 論文・発表でこのコーパスを使うときは，§4「制約」の記述をそのまま
> 引用できる形にしてある。**埋まらなかった穴を書かずに結果だけを示すのは，
> 代表性の主張として不誠実である。**

---

## 1. 母集団と標本

母集団は「1872–1959 年に日本語で書かれ，刊行された散文」である。
標本はそのうち**青空文庫が電子化し，著作権保護期間の満了したもの**に限られる。

この二重の絞り込みが，以下のすべての偏りの源にある。

- **保護期間**：1968 年以降に没した作家は原則として入らない。戦後の作家は，
  早世した者（織田作之助 1947・横光利一 1947・太宰治 1948・宮本百合子
  1951・坂口安吾 1955）に事実上限られる。
- **電子化の選択**：青空文庫の所蔵は，入力者の関心を反映する。明治前期の
  散文は薄く，探偵小説・児童向け読物は厚い。

**標本の偏りは，我々の設計の失敗であると同時に，利用できる資料の性質でもある。**
両者を区別して書くこと。

## 2. 設計目標

`config/design_targets.yaml` に機械可読な形で置いてある。

| 何を | 目標 | なぜ |
|---|---|---|
| 1作家の語数比 | 12 % 以下 | G² も PCA も word2vec も「誰が書いたか」を見ない。2割を占める作家がいれば，その文体が「時代の特徴」として出る |
| 1作品の語数比 | 8 % 以下 | 長篇1点が時代を代表してしまう |
| 区分内の最大作家 | 40 % 以下 | 時代スライスが一人の作家になっていないか |
| 1スライスの語数 | 50 万語以上 | 少ないスライスのモデルだけ語彙も近傍も貧しくなる |
| スライスの最大/最小 | 3 倍以内 | 「時代が違う」のか「標本が少ない」のかを区別するため |
| 各区分の女性作家 | 2 人以上 | 性別と時代の交絡を減らす |
| 夏目漱石 | 9 点以上 | 森鴎外 7 点との均衡（下記 §3） |

数値の根拠は「この値を超えると解釈が壊れる」という経験則であり，先行研究に
よる定数ではない。**変えてよい。ただし変えたら記録すること**（目標表を
書き換え，`logs/` に日付つきの写しを残す）。

## 3. 2026-09-26 の設計見直し

### 3.1 測ったこと

分析対象 101 点・6,211,023 語（`completeness` が `superseded` /
`merged` / `too_short` の行を除く）。

| 時代区分（6区分） | 点数 | 語数 | 語数比 | 区分内の最大作家 | 女性作家 |
|---|---:|---:|---:|---|---:|
| 1 明治前期（〜1886） | 3 | 67,381 | 1.1 % | 福沢諭吉 **100 %** | 0 人 |
| 2 明治中期（1887–99） | 14 | 703,600 | 11.3 % | 森鴎外 24 % | 1 人 |
| 3 明治後期（1900–11） | 15 | 674,022 | 10.9 % | 島崎藤村 37 % | 2 人 |
| 4 大正（1912–25） | 22 | 1,395,723 | 22.5 % | 森鴎外 32 % | 5 人 |
| 5 昭和戦前（1926–44） | 31 | 2,133,529 | 34.4 % | 海野十三 19 % | 2 人 |
| 6 昭和戦後（1945–） | 16 | 1,236,768 | 19.9 % | 宮本百合子 **50 %** | 2 人 |

作家の上位：宮本百合子 12.1 %（4点）／森鴎外 11.8 %（7点）／島崎藤村
9.3 %（5点）／海野十三 6.5 %／夢野久作 5.4 %／**夏目漱石 4.7 %（4点）**。
女性は語数の 23.3 %（20 点・9 人）。

### 3.2 見つかった4つの偏り

1. **漱石 4 点・4.7 % に対し鴎外 7 点・11.8 %。** 文学史的な位置づけに
   対して不均衡である。鴎外の語数は史伝『伊沢蘭軒』(316k)・『渋江抽斎』
   (107k) と翻訳『即興詩人』(162k) の長篇3点で作られており，**点数以上に
   語数で効いている**。
2. **明治前期は3点すべて福沢諭吉。** これは時代区分ではなく一人の作家である。
3. **昭和戦後は語数の 50 % が宮本百合子，59 % が女性。性別と時代が
   交絡している。** 「女性作家の語彙」として出てくるものの相当部分は
   「戦後の語彙」でありうる。
4. **明治前期〜中期の女性作家は樋口一葉ただ1人。**

### 3.3 決めた手当て

| 穴 | 手当て | 効き方 |
|---|---|---|
| 漱石の不足 | 『吾輩は猫である』(1905)・『それから』(1909)・『門』(1910)・『行人』(1913)・『道草』(1915) の5点 | 4 → 9 点。うち2点は大正期なので**大正の鴎外 32 % も同時に薄まる** |
| 明治前期 | 円朝『怪談牡丹灯籠』(1884) のみ（他2点は**未電子化**で断念。§4） | **帯としては埋まらない** |
| 明治前期の扱い | 学習では中期に畳む（`period5`） | 記述は6区分，学習は5区分 |
| 戦後の宮本偏重 | 織田作之助『世相』『土曜夫人』(1946)，横光利一『微笑』 | 戦後の男性作家を足して 50 % を薄める |
| 明治期の女性作家 | 三宅花圃『藪の鶯』(1888)。**解決済**（若松賤子『小公子』は未電子化で断念） | 前期〜中期を女性作家2人に |

取得の指示は `config/corpus_manifest.tsv`，候補の一覧と理由は
`metadata/expansion_candidates.csv` にある。

### 3.4 増補の結果（2026-09-26）

124 点を取得・解析し，メタデータを作り直した（分析対象 117 点・754 万語。
延べ 798 万語のうち，合本・分冊・短すぎる行を除いた数）。

| | 増補前 | 増補後 | 目標 |
|---|---:|---:|---|
| 点数／語数 | 101 点・621 万 | **117 点・754 万** | — |
| 夏目漱石 | 4.7 %（4点） | **11.8 %（9点）** | 12 % 以下・9点 ✓ |
| 森鴎外 | 11.8 % | 9.5 % | ✓ |
| 宮本百合子 | 12.1 % | 9.9 % | ✓ |
| 最大の作品（『道標』） | 7.3 % | 6.0 % | 8 % 以下 ✓ |
| 大正の鴎外 | 32 % | **26 %** | 40 % 以下 ✓ |
| スライスの最大/最小 | 3.2 倍 | **2.2 倍** | 3 倍以内 ✓ |
| 昭和戦後の宮本 | 50 % | 47 % | 40 % 以下 ✗ |
| 女性の語数比 | 23.3 % | **19.3 %** | 20 % 以上 ✗ |

**狙った効果は出たが，副作用が出た。** 増補した 133 万語のほとんどが男性
作家（漱石 55 万・長塚節・泉鏡花・田山花袋・徳田秋声・有島武郎・円朝）
だったため，**分母が増えて女性比が 23.3 % から 19.3 % に下がった**。点数は
20→21，作家は 9→10 人と増えているのに，比率は落ちている。
「増やしたことで却って偏る」——目標を数値で置いていなければ，
この低下は誰にも見えなかった。

もう一つ。明治後期の最大作家は**藤村 37 % から漱石 39 % に替わった**だけ
とも言える。集中は解消されたのではなく，移動した。次の増補では，
この帯に漱石以外を足す必要がある。

### 3.5 時代区分と初出年の食い違い（同日発見）

`period` は `year_first` の関数であるのに，**保存された値が古いまま残って
いた行が2件**あった。

| 作品 | 初出年 | 表の区分 | 正しい区分 |
|---|---|---|---|
| 有島武郎『或る女』 | 1919 | 明治後期 | 大正 |
| 水野仙子『四十余日』 | 1910 | 大正 | 明治後期 |

『或る女』は，索引が拾った 1911 年（『或る女のグリンプス』連載開始）で
明治後期に入ったあと，編者が初出年を 1919 に直したが，区分は取り残された。
**例外は出ない。** 大正の作品が明治後期の集計に混じり，時代の特徴語も
通時モデルも，静かに汚れる。

`00_extend_metadata.py` が**毎回初出年から引き直す**ように改め，直した行を
報告するようにした。`check_balance.py` も食い違いを検査する。

### 3.6 `narration` の `mixed` の境界（同日決定）

増補した『行人』をどう分類するかを機に，統制語彙の境界を決めた。
**地の文（matrix）の人称で決める。** 長文の書簡・手記・日記が挿入されて
いても，それだけでは `mixed` にしない——挿入部は
`<quote type="embedded">` として分離され `data/plain/embedded/` に
切り出されるので，語りの交替はそちらの側で扱う。**一つの事実は一か所に
記録する。**

したがって『こころ』（下巻 51 % が遺書）も『行人』（末尾が H の書簡）も
`first` のままとする。`mixed` は地の文そのものが交替する作品・枠物語・
作品集に限る（『光と風と夢』『青蛙堂鬼談』『少女地獄』の3点）。

定義は `01_build_workbook.py` の codebook と用語集に明記した。

## 4. 埋まらない穴（論文に書くべき制約）

以下はいずれも**増補では解決しない**。手当てを尽くした上でなお残る制約として，
結果とともに明示すること。

1. **明治前期（〜1886）は単独の時代区分として成立しない。** 3点・6.7 万語で，
   全点が福沢諭吉である。増補で足せるのは三遊亭円朝『怪談牡丹灯籠』(1884)
   1点のみであった（下記）。本研究では明治中期に畳んだ5区分（`period5`）で
   学習し，6区分は記述統計にのみ用いた。**区分の根拠が文学史ではなく
   標本の量であることを明記する。**

   **2026-09-26 の確認**：明治前期の補強に挙げた次の3点は，青空文庫の
   書誌索引（19,502 件）を作品名で検索して**不在を確認**した。いずれも
   保護期間はとうに切れており（中村正直 1891 年没・福沢諭吉 1901 年没・
   若松賤子 1896 年没），**未電子化**である。

   | 作品 | 意義 | 状態 |
   |---|---|---|
   | 福沢諭吉『文明論之概略』(1875) | 明治初期の漢文脈論説の基準点 | 未電子化 |
   | 中村正直『西国立志編』(1871) | 幕末明治の翻訳文体（漢文訓読体）の基準点 | 未電子化 |
   | 若松賤子『小公子』(1890) | 女性訳者による言文一致。性別・ジャンル・文体の三重の空白を同時に埋めるはずだった | 未電子化 |

   **「入れたいが入れられない」の理由は，保護期間だけではない。** 明治初期の
   散文は，著作権が切れていても電子化されていないことが多い。青空文庫を
   標本抽出の枠に使う以上，**電子化の偏りをそのまま受け継ぐ**。これは
   本コーパスに限らず，青空文庫由来の全コーパスに共通の制約である。
2. **女性作家の語数比は 23 % 前後で頭打ちになる。** 保護期間中のため
   入れられない作家に，野上弥生子・平林たい子・佐多稲子・尾崎翠がいる。
   公開されている女性作家の作品は短篇・評論が中心で，語数では稼げない。
   したがって**性別の比較は，語数比の等価性を前提にできない**。
3. **昭和戦後は，早世した作家に偏る。** 1968 年以降に没した作家が原則
   入らないため，「戦後文学」の標本としては代表性が低い。
4. **ジャンルは Fiction に偏る**（83 : 26）。随筆・評論・日記は薄い。

5. **島崎藤村が語数の 12.6 % を占める**（上限 12 %）。『夜明け前』4巻 47 万語・
   『新生』21 万語・『破戒』12 万語からなる。いずれもこのコーパスの目的
   （言文一致から自然主義への文体の推移）に不可欠で，外せない。
   **収録では下げきれない集中**として記録し，分析時に均す
   （`06 --max-per-author` ／ `08 --balance`）。

   なお，この 12.6 % は 2026-09-26 に**分冊を結合して初めて正しく測れた**
   数字である。それ以前は『夜明け前』第一部上・『家』上巻しか集計に
   入っておらず，藤村は過少に見えていた（§3.5 の前段）。

6. **昭和戦後の宮本百合子が 41 % 前後に残る**（上限 40 %）。林芙美子2点の
   増補で 47 % から下がるが，上限は割らない。**戦後は著作権の満了した
   作家が少なく**，薄める材料が尽きている。

   ⚠ したがって**「戦後の語彙」として観測されるものには，宮本百合子の
   文体が強く混じる**。戦後を論じるときは，作家を統制した比較
   （Step 7 の doc2vec）を併せて示すこと。

### 4.1 増補をどこで止めたか（2026-09-26）

女性の語数比 20 % と戦後の宮本 40 % を**同時に満たす**には，太宰治・坂口安吾・
岡本かの子・樋口一葉を含む8点（約 32 万語）の追加が必要だった。しかし
それは「目標の数値を満たすために作品を選ぶ」ことになる。

**採ったのは林芙美子『浮雲』(1951)・『晩菊』(1948) の2点のみ**である。
戦後の女性作家の長篇という一点で，2つの穴に同時に効く。残る不足
（宮本 41 %）は上に制約として明記し，分析時に均す。

> **目標値は，作品を選ぶ理由ではなく，選んだ結果を測る物差しである。**
> 数値を満たすことが目的化すれば，コーパスは「指標のために作られた標本」に
> なる。埋まらない穴は，埋めずに書く。

## 5. 収集による均衡と，分析時の均衡

**両方が要る。** 収集で下げきれない集中は，分析の側で均す。

| | 手段 | どこで |
|---|---|---|
| 収集 | 増補・上限の設定 | `corpus_manifest.tsv`／`design_targets.yaml` |
| 分析 | スライスの語数を揃える | `08_word2vec_diachronic.py --balance` |
| 分析 | 1作家あたりの上限 | `06_build_datasets.py --max-per-author` |
| 分析 | 作家を統制した比較 | Step 7（doc2vec・交絡の分離） |

⚠ **分析時の均衡化は，収集の偏りを消さない。** 捨てているだけである。
捨てた量は必ず報告すること（各スクリプトが落とした件数を出す）。

## 6. 増補したあとに走らせるもの

増補は**測り直しまで済んで完了**である。途中で止めると，メタデータの実測値
（語数・TTR・文語率）が古い本文のものになる。

```bash
# 0) 索引を最新にし，マニフェストが解決できるか先に確かめる
python3 scripts/02_fetch_aozora.py index --out data/aozora
python3 scripts/02_fetch_aozora.py resolve --manifest config/corpus_manifest.tsv --out data/aozora

# 1) 取得（1件1秒。未解決行は data/aozora/unresolved.csv に出る）
python3 scripts/02_fetch_aozora.py works --manifest config/corpus_manifest.tsv --out data/aozora

# 2) XML 化 → 正規化 → 形態素解析
python3 scripts/03_aozora2xml.py --in data/aozora/xhtml --log data/aozora/fetch_log.csv --out data/xml
# 03 の直後に必ず。03 は毎回 XML を作り直すので，03 のたびに結合は解ける
python3 scripts/03b_merge_volumes.py --xml data/xml --config config/merge_volumes.tsv
python3 scripts/04_normalise.py --in data/xml --out data/plain --config config/pipeline.yaml
python3 scripts/05_tokenise_unidic.py --in data/plain/full --out data/tokens \
    --lemma-policy mixed --expect-dict unidic-novel

# 3) メタデータを作り直す（実測値もここで測り直す。period5 もここで入る）
python3 scripts/00_extend_metadata.py \
    --meta metadata/corpus_metadata_v2.csv \
    --fetch-log data/aozora/fetch_log.csv \
    --candidates metadata/expansion_candidates.csv \
    --tokens data/tokens/tokens_surface --remeasure-all \
    --out metadata/corpus_metadata_v3.csv

# 4) データセットと検算
python3 scripts/06_build_datasets.py --tokens data/tokens/tokens_content \
    --meta metadata/corpus_metadata_v3.csv --out data/datasets --chunk 2000 --max-chunks 40
python3 scripts/99_validate.py --corpus data/plain/full --meta metadata/corpus_metadata_v3.csv \
    --tokenise-report data/tokens/tokenise_report.csv
python3 scripts/check_balance.py
```

**`02 resolve` を先に走らせること。** 解決できなかった行は
`unresolved.csv` に理由つきで出るので，**そこで見送りを決める**。
見送った作品は §4 の制約に書き足すこと。

2026-09-26 の実行結果：**127 行中 124 が解決，未解決 3**。未解決の3点は
いずれも未電子化のため，マニフェストから外した（§4）。
「著者が未登録」の診断は，**保護期間中とは限らない**（未電子化・表記ゆれの
可能性もある）。**作品名で索引を引いて区別すること。**

`02` は1件あたり1秒の間隔を置く（`config/pipeline.yaml` の
`sleep_seconds`）。**この値は下げないこと。**

増補後は，**新しい作品の初出年・ジャンル・語り手を人の目で確かめる**。
判断の要る列は `metadata/editorial_expansion.csv` に書けば
`00_extend_metadata.py` が拾う（`needs_review` が立った行が対象）。
